# Full Gaussian controls for the EAB study

The user changed the target to EAB. Extend the already evaluated two-/four-parameter Gaussian controls to all237 checkpoint identities, preserving the original trained networks, data and complete native test iterators.

Fit on the exact historical validation reservoir already saved by the primary suite (up to50000 coordinates from at most100 native validation batches/windows). Gaussian variance calibration uses mean `mu` and variance `A+B*sigma^2`; Gaussian affine calibration uses mean `c0+c1*mu` and that same variance. Constraints are `A,B>=0`, with variance floored at1e-12. Inputs use the native100-member mean and ddof1 scale floored at1e-6. There is no division by the native scale in this likelihood family, so all supplied fitting coordinates enter the objective.

Use the unchanged `fit_gaussian` implementation from the previous low-parameter control study: analytic Gaussian CRPS and its analytic gradient, L-BFGS-B, two prespecified initializations, max200 iterations, ftol1e-12, gtol1e-7, maxls50. Select the successful candidate with lowest fitting objective; retain all optimizer outcomes. Do not select parameters using test data. An unsuccessful fit is a task failure for inspection, not an accepted result.

Expose each fitted Gaussian through100 deterministic midpoint quantiles. Score Native/GaussianVariance2P/GaussianAffine4P on the full original test iterator using seed=training seed+30000. Share every native forecast and test target. The diagnostic partition and three historical event thresholds are identical to the completed six-method primary suite. Verify Native CRPS/QICE/MSE and full iterator counts against that suite before joining results. All point metrics, conditional coverage counts, event scores and fitted coefficients are retained.

This is an additional full-test experiment, not a reservoir-only replacement for the primary benchmark. Training/inference jobs use only GPU cards unoccupied by the remaining DeepSTUQ workers. No reduced backbone, model retraining, MAD, test-based gate or shortcut estimator is introduced. Label these controls by their actual Gaussian formulas rather than claiming reproduction of every EMOS variant.

# State-assignment intervention protocol

The current seven-backbone study adds the twelve DeepSTUQ tasks under this exact protocol, for249 tasks in total. Its native traffic-flow units change neither the source assignment intervention nor the common-coordinate scoring rule.

All 237 checkpoint tasks use their existing validation fitting coordinates and the same uniformly retained test-coordinate cohort collected during complete native test traversal. These are explicitly retained-cohort controls, separate from complete-test quality results.

The genuine DC16, a global residual template, and five shuffled residual-to-state assignments use identical native forecasts and target coordinates. Shuffle seeds are training seed +80000 through +80004. Only surviving standardized residual values are permuted; the source-validity mask, mean/scale boundaries, local source counts, 128-source fallback rule, global pool and 20,000-order-statistic cap remain fixed. State diagnostic boundaries are those of the training-fitted native partition, shared by every method. No neural network is retrained.

The genuine compiled template must match the independently saved deployment benchmark template exactly. Its CRPS, QICE, point metrics and Brier scores must also match the earlier 50,000-budget control. Coverage and event-count arithmetic are independently reconstructed. Five shuffles are averaged within each task before equal configuration averaging within each training seed and sample standard deviation across seeds 1,2,3. Raw scores for every shuffle remain available. Manuscript SD displays use actual sample standard deviations rounded to three decimals.

# NsDiff forecast-length correction

The current experiment uses prediction length192 for ETTm1,ETTm2 and ExchangeRate, with three independent training seeds each. These nine tasks replace the prior24-step tasks. Other backbone/dataset tasks are unchanged; the combined benchmark remains83 configurations and249 checkpoints across seven backbones. Earlier24-step results are retained as historical records and are not relabelled or pooled into the current192-step results.

Native NsDiff is retrained from scratch with the same context168, training batch32, Adam learning rate0.001,50-epoch maximum,patience10, diffusion20steps,beta_end0.01,rolling variance window24,and other saved dataset-specific settings. Only `pred_len` and the derived output dimensions change. Validation empirical CRPS selects each checkpoint; test metrics do not select model settings. All three uncertainty/conditional networks are trained and saved by the native implementation.

Training forecasts fit DC16/DC64 from at most100 native batches and a50000-coordinate uniform reservoir. Native validation iterators supply state diagnostics and the common correction-fitting reservoir. Eight primary/Gaussian methods and training DC64 share one complete native test prediction pass, the original100-member output interface, numerical floors, source rules and seeds. A separate CommonMetrics accumulator recomputes Native scores on identical arrays to check the reliability-metric implementation. Gaussian methods use the same native samples and validation coordinates; their Native entries refer to that shared pass.

The unchanged budget/source controls,five state-assignment permutations,three event thresholds,point/state metrics,and exact compilation/query benchmark are then evaluated. The standalone auditor checks actual192-step output shapes,fitting horizon IDs,native training identities,complete test populations and every retained three-seed task. Primary/Gaussian/state/compiled auditors retain their existing arithmetic checks. Statistics replace nine task identities before aggregation, rather than adding configurations. Neural model weights remain private; reproduction trains them locally.

## Observed numerical overflow

ETTm2 seed2 produced a float32 attention-temperature overflow at zero-based epoch13,batch399: the largest log-temperature was115.08797454833984. The unchanged exponential is outside float32's finite range. Replaying the saved finite epoch state reproduced the failure. The existing de-stationary-attention precision implementation,also used for TMDM,promotes otherwise overflowing exponentiation/scores to float64 and centers attention logits using softmax invariance. Normal float32 forward values and gradients are bitwise identical in the ordinary path. The original failing batch then has finite loss and all finite gradients.

That task resumes from the last complete finite epoch boundary with all three native networks,optimizer and early-stopping state restored,and the original per-epoch random-seed policy. Training continues under the same50-epoch maximum andpatience10; no batch is dropped and no test metric selects the repair. The checkpoint history retains every preceding complete epoch. A later resume starts from the complete finite epoch18 state after a nonfinite validation prediction at epoch19. Nonfinite validation candidates receive an infinite selection score and count as no improvement under the unchanged patience10 rule; their JSON history records null CRPS and the invalid-candidate flag. They are ineligible for checkpoint selection. `train_nsdiff_h192.py` supplies this precision policy for new from-scratch replications. The corrected-task inference interface uses the same policy. Complete native test replays verify unchanged scores for the other eight completed tasks. The architecture,objective,optimizer and model hyperparameters are unchanged.
